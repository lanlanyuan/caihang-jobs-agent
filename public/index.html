个人使用 · 不收集简历：本网站是供个人自助使用的公益小工具，不设账号、不收集或留存任何个人信息与简历数据。简历仅在你主动上传后于运行内存中即时解析，解析完成立即释放，不写入磁盘、不写入日志、不用于其他用途，也不转发给第三方大模型（本版未启用 LLM）。请勿上传与本次求职无关的敏感个人信息。
公益提示：本专栏岗位来自公开社区库，仅回链企业原始公告，不复制数据库、不随包分发、不收费。岗位信息以企业官网为准，投递前请务必核验；如涉及侵权，请通过 GitHub 地址联系删除。
